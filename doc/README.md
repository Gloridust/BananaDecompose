# BananaDecompose 文档

用 Nano Banana 2（`google/gemini-3.1-flash-image`，走 OpenRouter）生成图像，并把它变成**可编辑的图层 + 可改的文字**。

中间是一张节点画布，每条方案分支的每个中间产物都是一个节点。一次生成 = 一轮 = 若干分支；一张画布可以叠加多轮。

## 30 秒版本

**问题**：AI 生成的图是一张拍平的位图，改一个字就得重新生成整张。

**两条路**：

| | A · 生成即分层 | B · 事后拆解 |
|---|---|---|
| 思路 | 先规划结构，元素逐个独立渲染，文字全程不进像素 | 先出一张拍平的成品，再拆回图层 |
| 可编辑性 | **设计出来的** | **抢救出来的** |
| 精度上限 | 无损 | 约 PSNR 26 / LPIPS 0.09 |
| 能处理外来图 | ❌ | ✅ |

**三条绕不开的约束**：

1. Gemini 系图像模型**全都不输出 alpha 通道** → 透明必须算出来（[抠图](./matting.md)）
2. Gemini 的 `box_2d` 精度不足以定位文字，`fontSize` 是猜的 → 几何必须从像素量（[文字回收](./text-recovery.md)）
3. 底板上还留着被抬走的东西就不是分层文件 → 背景重建是强制的（[设计决策](./decisions.md#背景重建没有开关)）

## 快速开始

```bash
npm install
cp .env.local.example .env.local   # 填入 OPENROUTER_API_KEY
npm run dev
```

不填 key 也能打开 <http://localhost:3000/selftest> —— 抠图数学、字形拟合、画布布局三项自检，全部用已知真值验证，不消耗任何 API。
