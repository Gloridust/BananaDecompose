# 界面

## 节点画布

每条分支的每个中间产物都是一个节点，边指回它的来源。

```
提示词 ──→ 规划 ─┬─→ 渲染(白/黑) ──→ 抠图 ──┬─→ 成品场景  A·双渲染
                │                          │
                ├─→ 渲染(品红)  ──→ 抠图 ──┼─→ 成品场景  A·色键
                │                          │
                └─→ 背景板 ────────────────┘   ← 标着「共享 ×N」
```

**这张图本身就是那个论证。** "同管线共享上游所以对比公平"曾经只是文档里的一句话，现在它是画面上一个规划节点扇出多条链路。

### 手势

| 操作 | 行为 |
|---|---|
| 双指拖动 / 滚轮 | 平移 |
| 双指捏合 / ⌘+滚轮 | 以光标为锚点缩放 |
| 拖空白处 | 平移 |
| 中键拖动 | 从任意位置平移 |
| 右下角「适应画布」 | 重新框住全部节点 |

跟 Figma、tldraw 一样的约定。拖动时不会选中卡片文字，`touch-action: none` 防止浏览器手势打架。

### 开关

- **分支开关**（顶栏）+「只看这一条」
- **节点开关**（卡片右上角 ✕），顶栏可一键恢复

关掉一条分支时，只被它用到的节点连边一起消失；**共享节点因为还有别的分支在用而留下** —— 这个行为本身就告诉你哪些是共用的。

### 节点状态

| 颜色 | 含义 |
|---|---|
| 黄色边框脉动 | 正在跑 |
| 灰色边框 | 完成 |
| **黄色 ⚠ 文字** | 完成但有降级（例如背景重建被拒） |
| 红色边框 | 失败 |

黄色是"降级"，红色留给真错误 —— 一条降级但产出可用的分支不该看起来像崩了。

### 画布是文档

- **+ 新建画布** —— 清空，从头开始
- **标题栏下拉** —— 在最近的画布之间切换
- 已经有画布时运行，会**追加一轮**到当前画布，而不是顶掉它

共享上游按**轮次**作用域，所以一张画布可以叠加多轮：跑一遍扫描、改个参数再跑一遍，两组并排。

### 折叠

左侧和底部面板都能收起，画布占满窗口。状态跟设置一起持久化。

## 图层编辑器

点**成品场景**节点打开浮层。画布负责讲"怎么来的"，编辑器负责证明"真的能改"。

- 拖拽移动、四角缩放（文字随框缩放）
- **双击文字图层直接改字**
- 字体、字号、字重、字距、颜色、对齐、斜体
- 图层顺序、显隐、删除
- 导出 **PNG / SVG / JSON**

SVG 里的文字是 `<text>` 节点而不是描边路径 —— **这是整个 demo 的验收标准**。

选中「保留原始笔画」的文字图层时，属性面板给的是一个文本框 + **「按原样式重绘」**按钮，因为那层是像素不是文本节点。

## 量化指标

每次运行结束后从**已有像素**里算出来，不额外花钱。

| 指标 | 含义 | 适用范围 |
|---|---|---|
| **软边占比** ↑ | 存活像素里半透明的比例。羽化边被正确还原时不该是 0 —— 硬阈值抠图会把它压平 | 全部 |
| **存活面积** | 抠完剩下多少画面，太低说明主体被啃掉了 | 全部 |
| **底色残留** ↓ | 仍贴近键色的像素比例 | 仅彩色底（色键 / 灰底）。双渲染没有单一键色，报 `—` |
| **重建 PSNR / L1** | 图层叠回去和原图的差距 | 仅拆解管线 —— 只有它有原图可比 |
| 文字来源 | 「未入像素」还是「OCR 回收」 | 全部 |

对比表里每行最优值标绿。**`—` 是"不适用"，不是"没测出来"** —— 硬凑一个数出来只会让人比错东西。

## 一键评测

左栏底部，把选中的方案用同一条提示词挨个跑一遍，全部落到同一张画布。

同管线的各组共享上游产物（见[两条管线](./pipelines.md#共享上游)），所以表里每一行的差异只来自被测的那个变量。

面板实时显示组数、出图次数和粗估成本。

## 历史

`/history` 列出所有画布。展开任意一张看：分支缩略图、完整指标表、这张画布上哪些节点被共享了。「在画布打开」回到工作台继续编辑。

索引存 localStorage（列表秒开），节点数据存 IndexedDB（图像是 data URI，5MB 配额装不下）。

## 自检

`/selftest` 三项验证，**不消耗任何 API**：

1. **抠图数学** —— 已知 alpha 的合成图，逐像素比
2. **字形贴合** —— 已知字号/位置/颜色的文字 + 故意画歪的粗框
3. **画布布局** —— 合成的三分支画布，点成品场景节点可以打开真正的编辑器（合成场景，能试拖拽、改字、圈选）

字体加载不上时会顶出一条黄条说明哪些没加载 —— 那种情况下测量拿到的是 fallback 度量，下面的数字不作数。

没配 key 也能打开。跑真实管线之前先看这里。

## 圈选重绘

编辑器顶栏的 **⌗ 圈选重绘**：在画面上拖一个框，写一句要改什么，交给图像模型重画那一块。

```
圈选区域
  → 连同一圈周边裁下来（默认外扩 18%）
  → 作为 reference 送给图像模型 + 你的指令
  → 边缘羽化
  → 作为新图层叠回原位
```

三个设计点：

- **裁片带周边**。模型需要看到邻域才能把光照、配色、笔触接上；只给孤立的一块，回来的东西像贴纸。
- **边缘羽化**。重画出来的图是不透明到边的，直接贴会留一个可见的矩形，哪怕内容对得上。最后几个像素做 smoothstep 渐隐后就化进底下了。
- **落成独立图层**，不是拍进底板。**在分层文件里，一个关不掉也移不动的编辑不叫编辑，叫提交。** 补丁层可以隐藏、移动、删除、调层序。

选中某个元素图层时，属性面板里还有 **「重画这个图层」** —— 同一趟流程，只是范围限定在一个边界已经很干净的图层上，位置和尺寸保持不变。

保留原始笔画的文字图层给的则是 **「按原样式重绘」**，见[文字回收](./text-recovery.md#保留原始笔画)。
